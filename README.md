# 挤地铁大作战 / Subway Roguelike

这是一个独立 Godot 项目，不属于 `cs-demo-highlights`。

## 当前定位

第一版 MVP：5 站固定线路，不换乘。玩家需要在前 4 站留在车上，不能被挤下车；第 5 站到达后必须从提示方向的车门下车，如果关门时还没下车则失败。
